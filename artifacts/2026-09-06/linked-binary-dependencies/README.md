## 统计修正和限制

初版分析只按VMA区间累加SHF_ALLOC交集，TLS `.tbss` 与后续普通段的地址重叠使其重复581字节。保留初版完整JSON和精确源码SHA；最终v2同时匹配GNU map输出段名称与ELF段，分配段交集总量为21,531,404字节，其中文件段21,448,499、NOBITS82,905；其余输入段记录10,165,061字节。**这些是链接器输入段贡献统计，不是去重后的程序大小、峰值内存、符号级所有权或许可证义务结论。** 独立原始map/ELF解析已得到同一最终计数，最终报告复核另存审查记录。

实际链接scope为4GiB、swap0、CPU200%且affinity8/10；六份采样的max/OOM/swap均0，采样memory.current峰值143,155,200字节、host available最低17,469,009,920字节。采样峰值不是精确进程RSS。
