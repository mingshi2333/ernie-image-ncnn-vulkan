# 横竖图与 512×512 映射加载，2026-09-07

本轮验证同一个共享包的非正方形出图，以及 512×512 映射加载与原版的逐字节一致性。运行源为 `1a92431`，原生模型运算和旧数值容差没有修改。容差是此前助手选定的开发诊断值，不代表官方标准或广泛感知质量。

## 运行时尺寸实图

两个原生任务均使用此前实际安装验证的 Linux Vulkan 二进制，SHA256 为 `979f56f377c7fb760e256bd9dcdceb33f3050bc73f115d494ad7ead0e2afe380`。实际命令隐藏项目源码、禁网，将共享包只读挂载到独立目录。提示词为 `A red apple on a wooden table, soft daylight, realistic photo.`；15 个真实 token 自动选择 source32，保留 64 个 DiT 文本槽。原生端运行 CPU Vector 文本编码、8 步 Vulkan FP32 和 CPU direct VAE。两张原生图均已实际查看，清楚呈现木桌上的红苹果，横图前景还有一片叶子。

共享包 manifest 为 `21b6bc8deae17418c22257b52e928ee048a372342a2517bcb954276257c21d1a`；两种尺寸使用同一个原始 source32 manifest `9cc1dc0e605256e405a049b6a8d58f98a9f138b2a16c6d40be6bb35595743154`。官方权重来源补充仍为已认证 source64，全部 71 个非图运行资产一致。每个尺寸的官方/原生共享保存的初始 FP32 字节；两个矩形等面积，其初始数组是同一字节流的不同形状，不能计为两个独立随机种子。

官方 DiT 按块运行 CUDA FP32，禁用 TF32；文本、heads、Euler 和 VAE 在 CPU。每块结束后释放闲置 CUDA 缓存，沿用上一轮代码。本轮只在独立工作脚本中增加显存观察 hook 和进程归属采样。25 个张量边界由独立 NumPy FP64 运算重算误差，同时核对 token IDs、目标配置、源码/二进制绑定和各自解码张量到 PNG 的量化结果。

## 首次官方竖图中断

原批次的第一个官方阶段在 36.774 秒后被监督程序终止，整卡显存采样为 6767 MiB，超过原 6144 MiB 保护线；max、OOM 和 OOM-kill 均为 0。原生阶段当时尚未启动。该失败保留在 `portrait-guard/` 和 `initial-batch/`。

在相同模型代码、权重、输入和限制下，增加观察日志的重跑完成全部 8 步，整卡显存峰值为 3077 MiB，模型进程 NVML 采样峰值为 1216 MiB。原尝试保存的六个条件输入与重跑逐字节一致。首轮没有记录进程级显存归属，因此不能确定瞬时升高的根因，也不能把重跑成功写成已修复某个确定的内存泄漏。该中断不是 OOM，不证明本机容量不足。

## 映射加载的实用尺寸对照

候选构建只开启已有 `ERNIE_EXPERIMENT_MAPPED_MODEL_LOADING` 选项。构建后恢复了原 OFF 配置，恢复出的原生二进制与上述安装版逐字节一致。候选二进制为 `89ccaa55797eda7ba9121813ef6ecbd55979a4ba49fe2210c4736cd19383e013`。默认仍为 OFF，独立 PE 不受这个开关影响。

候选复用上一轮 512×512 的模型、提示词、初始数组、8 步、CPU2、FP32、Vector 文本、CPU direct VAE 和 trace 配置。全部 28 个 trace 文件、25 个 FP32 张量（4,981,760 元素）和 PNG 逐字节相同，所有浮点元素有限。该原版已通过完整官方对照。候选 PNG 的 SHA256 为 `bf87214d21461bfda96529830b28a5b7630ef0dcf307c0172f1666fc64044e28`。

监督区间由原先 466.868 秒到本次 309.793 秒，单次观测少 157.075 秒（33.6%）。两次运行没有统一文件缓存状态，不能据此宣称正式提速百分比或超过参考项目。实际观察到 61 个只读模型文件映射，确认该次运行使用了映射路径；0.5 秒采样可能漏掉寿命短的映射，61 不是全部加载对象的保证计数。

映射运行未触及 16 GiB 进程组上限，max/OOM/OOM-kill 都是 0。一次中途记录的 memory.current 为 14,748,086,272 字节，其中 file 为 14,339,129,344 字节、anon 为 367,812,608 字节；该时刻原生进程 VmRSS 为 945,496 KiB，内核当时记录的 VmHWM 为 1,353,684 KiB。这是中途观察，不能写成包括随后 VAE 解码在内的完整峰值 RSS。

此前 [64×64 映射记录](../mapped-model-loading/README.md) 的 10 GiB 上限事件保留。本轮不同限制、缓存状态和几何范围不能覆盖或改写那次结果。
