# 共享 768×768 首次预测的 DiT 阶段对照

已有阶段诊断命令现在支持经过认证的共享包。本次实际执行官方参考和原生 Vulkan 的完整单步跟踪，两边输出分别逐字节复现各自已有预测。独立重算 44 个阶段后，**相对误差增长最明显的是 block 17、18、19（从 0 编号），相邻阶段各约增至 2.1 倍。** 这是自由传播的阶段对照，尚不能区分输入误差放大与块内新增误差，也没有证明这些块存在实现错误。

本项没有完成完整轨迹修复，原 [768 完整对照](../runtime-squares/README.md) 的 18/25 保持。下一次有意义的诊断应给选定块提供完全相同的输入，分离局部计算差异；无需重跑本次不变的完整单步。

## 实际执行与比较

运行的是新增共享包支持后的实际顶层阶段命令。官方子进程先完成 CPU heads / CUDA FP32 的 36 块参考，每块结束释放无用 CUDA 缓存，退出后才执行原生 Vulkan。原生使用共享 source32、48×48 packed grid、15 个有效文本 tokens、32 文本桶和 64 个 DiT 槽、显式 RAM 权重、stdio、缓存 0、2 线程。本次没有运行原生文本、PE、Euler 或 VAE。

六个准备后的输入均与上轮全部官方输入的单步命令逐字节相同。官方块仍在 CUDA 上计算位置三角函数，原生使用保存的 CPU 表，相关末位差异仍包含在对照中。

- 官方最终预测逐字节复现完整官方参考 `731ebbab…` 的 prediction-0。
- 原生最终预测逐字节复现上轮同输入、无阶段跟踪的原生 prediction-0。
- 8 个输入 head 输出和 36 个块输出共 44 个阶段，每侧合计 358,903,808 个有限 FP32 值。
- 独立 NumPy FP64 重算全部阶段误差及图像/文本分区，结果与原 PyTorch 统计一致。
