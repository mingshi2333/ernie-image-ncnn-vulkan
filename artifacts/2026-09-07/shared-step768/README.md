# 共享包 768×768 第 7 次预测：复现与单项输入替换

本轮将完整 768 开发样例的 `prediction-6` 偏差缩小到进入该步的 latent。**同一原生实现换入官方 latent 后，预测距离大幅下降；只替换文本条件没有类似改善。** 这定位了本步的主要敏感输入，尚未证明更早偏差由哪个算子引入，也没有修复完整自由轨迹。原 [768 完整运行](../runtime-squares/README.md) 的 18/25、PNG 最大差 2 保持。

## 实现与执行范围

现有 `ernie-block-sequence-runner` 增加 `--package`、`--valid-text-tokens` 和 `--threads`，调用生成器同一个 `ModelPackage` 进行全包校验、文本桶选择及内存中的图实例化，再调用现有 `run_dit`。原始 block/head 目录入口保留。未添加另一套模型数学、未生成临时模型图、未修改原生生成器的精度或默认内存策略。

源码基点为 `36973c2af6f439156f7f0ab1fb9709d37617274b`，源码补丁只涉及两份 probe/CMake 文件，完整 334 项源码清单保留。冻结探针 SHA256 为 `1d754f49534434cf8e3882b271714060394f5233b6a13eb3a0cf2c7e7bcb665a`。先完成原生复现与官方输入计划 `78910ae49ee1542689bc33e4adc3ebb2eb690f339d631716e8e939c27300e9aa` 的两次执行，再根据结果冻结两项条件替换；后者的独立计划保留在 `factors/plan.json`。

四次均为相同 Linux Vulkan 探针、共享 source32、15 个有效文本 tokens / 32 文本桶 / 64 DiT 槽、48×48 packed grid、36 blocks、FP32、RAM 权重、stdio、缓存 0、2 线程。每次只执行一个 DiT 预测，原生输入 head、36 blocks、输出 head 全部参与；无文本编码、Euler 或 VAE 执行。来源是之前完整原生/官方运行保存的输入与预测。原生时间特征由同源生产函数重建为 `5919ea08…`；官方时间特征为 `ae3da329…`，时间值都为 571.4285888671875。新探针必须先逐字节复现原生预测，才执行后续对照。

## 结果

所有输出均含 294,912 个有限 FP32 值。表中的官方距离以原完整官方预测为参考。

| 单步输入 | 对官方预测的 NRMSE | 最大绝对误差 | 结论与范围 |
|---|---:|---:|---|
| 保存的原生输入 | 0.00229427042 | 0.235822916 | 新探针逐字节复现旧原生预测；原生复现误差为 0 |
| 官方 latent、文本、时间特征、位置表与 mask | 4.06143732e-6 | 0.000172257 | 同输入单步通过原 NRMSE 0.003 / 最大误差 0.0602270748 门槛 |
| 仅将原生 latent 换为官方 latent | 4.12554021e-6 | 0.000242591 | 单项条件替换；其他五项输入保持原生字节 |
| 仅将原生文本换为官方文本 | 0.00229646433 | 0.236498833 | 单项条件替换；其他五项输入保持原生字节 |

后两行是混合输入，**不套用完整官方质量门槛，也不计为自由运行验收**。结果支持“本步偏差主要受进入该步的 latent 影响”，不能将这些非线性条件效应相加为因果百分比，不能据此认定文本编码对更早轨迹完全没有影响。全部官方输入仍包含已知的 CPU/CUDA 位置函数最后几位差异。下一步应考察更早的偏差引入和逐步放大，避免仅调高第 7 次预测或文本条件的精度。

另用每一端自身保存的 sample 和 prediction，以官方 FP32 sigma 差进行分开的 FP32 乘、加，重算 8 次 Euler 更新。原生 8/8、官方 8/8、共 4,718,592 个输出值逐字节一致；可复现审阅脚本也复算出相同的 16 条记录。此结果排除了本样例已保存状态更新与该公式之间的差异，不等于排除前面 DiT 计算中的舍入累积。
