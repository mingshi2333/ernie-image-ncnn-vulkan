# 固定1376×768对应的4192-token DiT block链

真实权重、Vulkan FP32 的36个block连续运行已通过全部36个中间输出门槛。逐层对照同一保存输入出发的官方CPU参考，完整复算618,135,552个FP32输出元素；全部有限，未选取少量行替代完整输出。最后一层也是本轮最差层：NRMSE4.376633118835e-6、最大差0.07763671875，通过既有连接链门槛NRMSE2e-4及最大差5.096016015625。门槛在原生运行前固定，未按结果调整。

先完成block0单组件验证：17,170,432元素，NRMSE2.722227869231e-6，通过原单块NRMSE2e-5及最大差门槛。完整链的第0层官方/原生输出分别逐字节复现该单块端点；最后原生输出与第35层trace也逐字节相同。完整链的官方侧复用已执行的第0层参考，再实际执行其余35层，没有为复用端点虚记一次forward。

四个阶段均exit0，MemoryMax16GiB、swap0、CPU12/14两核预算，host可用最低13,083,172,864字节；memory.events的max/oom/oom_kill等均0。官方单块原导出器内部Torch4线程、官方链2线程、原生ncnn4线程。原生验证器还以100ms采集整卡显存，外围500ms守卫保持6144MiB上限；这些数值不等于本进程精确显存。原生整链GNU time记录峰值RSS944,776KiB，与cgroup范围不同。本轮不是速度或内存配对基准。

固定输入是合成hidden state、shared AdaLN和官方位置编码，packed网格H48/W86、text bucket64（有效62）、总tokens4192。保留每个原生图的完整候选SHA及规范图SHA；36个bin仍是原1024包的全部原字节，官方36份权重与原包source_weights匹配。311个项目source快照、已认证2822个CPU参考runtime文件、封存runner及按阶段使用的完整权重在执行前后核对。这里复用已认证runtime，不声称重新枚举了所有瞬时动态加载库。
