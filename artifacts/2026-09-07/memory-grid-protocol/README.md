# 四种 RAM 权重加载配置的预先固定比较

2026-09-07，已固定同一最终程序的四组开发比较并启动串行批次。**本目录记录运行前协议和检查，不包含完整性能结果，不改变默认设置。** 原始完整运行记录保存在 `/var/tmp/ernie-memory-grid512-v1`，总状态见该目录的 `progress.json`；结果收集器只有在全部 16 次成功后才生成配置汇总。

|---|---|---:|

每组 1 次预热、3 次测量，16 次均启动全新生成进程和独立缓存目录。预热顺序由固定随机种子 20260907 决定，随后三个测量轮依次循环移动位置。包含预热的四轮中，各组在每个位置恰好出现一次；三个测量轮本身不构成完全平衡或统计显著性结论。

所有运行明确使用 `--dit-weights host`，避免自动显存策略成为额外变化。相同苹果提示词、15 个实际 token、共享 source32/64 DiT 槽、512×512、保存的初始 FP32 噪声、8 步 Vulkan FP32、CPU Vector 文本、CPU direct VAE、2 线程、GPU0；RAM 余量 3072 MiB，GPU 余量保持默认 512 MiB（显式 host 下不参与选择）。没有开启 PE、张量 trace 或分配插桩。
