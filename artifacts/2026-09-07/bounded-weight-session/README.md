# 有界 RAM 权重缓存的实际出图回归

2026-09-07，新增请求内 `WeightSession`，在可选预算内复用已经准备的 Vulkan FP32 DiT 权重。真实 512×512、8 步生成完成；6 个块跨步骤命中 42 次，36×8 次块调用只加载 246 次。25 个 FP32 张量、4981760 个有限元素和最终 PNG 与此前无缓存原生基线逐字节相同。默认缓存预算为 0，实时 GPU/RAM 选择仍默认 auto。

## 实现

- `weight_session.*` 管理不可复制的租约、缓存计账、固定准入集合与内存压力回收。逐块扫描时保留已准入的子集，其余块流式加载，避免小容量 LRU 在每轮 36 块扫描中全部未命中。
- 每块先检查主机可用内存与 Linux 当前 cgroup-v2 及祖先的剩余额度。不足时回收空闲缓存，不回收活动租约。无法取得可用量时不新增缓存，统计 unavailable。其他平台的主机余量读取尚未实现，本可选缓存会继续流式执行。
- 载入后核对固定 ncnn 的 Gemm/RMSNorm 权重，按实际 memory type 排除任何 device-local 权重，包括 ncnn 内部 host→device 回退。未知层或低存储精度不会进入缓存。输入/output heads 继续流式执行。
- 计账包含去重后的 Vulkan 权重 buffer memory requirements、保留的 CPU 权重负载及每 Net 64 MiB 工程余量。该预算约束缓存子集，不是整个进程 RSS 上限；当前流式块、加载临时数据、激活和驱动开销仍另占内存。示例 6 GiB 缓存与默认 3 GiB RAM 余量均可配置，不是模型硬件门槛。
- 每块的 GPU 命令完成、extractor 销毁后才将租约放回空闲缓存。取消销毁空闲项；活动租约继续拥有 Net，直到调用者结束使用。没有后台线程、异步预取或失败命令恢复。缓存于 DiT 阶段结束后、VAE 之前释放。
- 复用只涉及权重和已创建的 pipeline，不复用 DiT K/V、hidden states 或预测。修正查询分块提交计数为本次执行增量，避免复用 Net 后把历史累计值重复计入当前步骤。
- 公共请求末尾新增 `dit_cache_mib`、`ram_reserve_mib`，保留旧位置初始化与标准库头文件边界。`--dit-cache-mib` 要求 Vulkan FP32 和 auto/host 权重；默认关闭。CLI/API 输出命中、加载、缓存峰值、回收和查询缺失计数，trace 新增 `weight-cache.txt`。

## 小型与安装验证

CPU/Vulkan 及安装消费者共 14 个受影响 CTest 执行全部通过、无跳过。状态测试覆盖预算超限、顺序扫描复用、RAM 压力、模型/请求身份变化、读盘失败、未完成租约、移动、取消与会话提前销毁。真实 Vulkan 小型 GEMM 连续三轮返回精确 `[10,-54]`，两块缓存命中 4 次、加载 5 次，峰值计账 150994944 字节；真实主机余量查询识别了测试的 4 GiB cgroup 限额。

最初构建尝试的服务工作目录遗漏，以及 Vulkan 查询符号命名空间错误，均在完整模型运行前修复。两种构建及随后所有受影响测试通过，见 `checks.json` 与相应日志。无 ncnn 上游源码修改，没有改变已记录数值门槛。

## 真实 512×512 执行

与前次受控 RAM 回归相同：原生 15-token Vector 文本、source32/64 DiT 文本槽、同一保存初始 latent、8 步 Vulkan FP32、CPU direct VAE；网络禁用、源目录隐藏、共享模型只读。冻结 387 个源码、二进制、输入和基线绑定，运行前后及最终比较均核对。

继续使用上一实验的 `--dit-weights auto --gpu-reserve-mib 8192`，只增加 `--dit-cache-mib 6144 --ram-reserve-mib 3072`。8192 MiB 是主动覆盖 RAM 分支的测试输入，不是产品默认值，也没有实际占满显卡。候选映射加载与分配器插桩都为 OFF。配置、完整命令与源码身份见 `plan.json`、`build-identity.json`。
