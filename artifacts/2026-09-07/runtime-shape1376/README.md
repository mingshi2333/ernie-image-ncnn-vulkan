## 实现与实际输入

- Rust 包解析器验证完整源包后，按源 manifest 选择登记的目标尺寸，并分别保留原始配置和目标配置。
- C++ `ModelPackage` 在内存中实例化经过完整图指纹约束的字段。所有组件继续使用 `ComponentFiles`，没有增加另一套生成流水线，也不生成临时图文件或按尺寸复制权重。
- 原始源 manifest 为 `72bb195a2d0b3ef2a25f873666f51f4bbec4b391744518597be87206a551efc1`。64 个实例化图与独立执行过的固定 1376 包逐项比较相同，忽略空白；71 个非空间资产的内容绑定不变。
- 苹果提示词为 `A red apple on a wooden table, soft daylight, realistic photo.`，含 BOS 共 15 tokens；PE 关闭、CFG=1、八步，显式使用文本 Vector down reduction。两次原生运行使用同一保存噪声，未用官方 embeddings 代替原生文本。
- 初始噪声 SHA256 为 `b2a384ece486abdaa5cd3a110307f8a9b1b934c591e4a8bbcaa82902876ffe20`，官方完整参考 fixture 为 `930d1593ea6e4246e03edd990fbdf3a805de1b378ea2a5bbc8b15695a762f128`。本轮复用这个已执行的官方参考，没有另算一次官方模型。
- 冻结程序 SHA256 为 `1590279970e6a7b911cea0d8a6b372e9d81b789b7c823415a0c57e45485d247d`，311 个源码/构建文件和 459 个计划绑定在运行前后保持不变。构建为 Release、`-O3 -DNDEBUG`，Vulkan 分配计量开启、映射加载关闭；目录名称中的 `o2` 不是优化级别。

目标文本容量保持 64，不能把 2048 桶自动换入。1376 目标也不会暴露源 1024 的 VAE encoder；图生图编码器继续按实际尺寸分别登记。其他尺寸、768×1376 方向和 1376/s2048 尚未开放。该实现只完成一个新增运行时目标。

## 可直接使用的本地包

已用现有打包器生成 `models/turbo-shared`。85 个对象共 **23,271,662,883 字节**，都是无内部软链接的普通文件，且与原测试对象是不同 inode；运行不依赖原测试包。打包器和原生程序分别完成全部对象校验。新包 manifest 和对象清单与实际出图所用包完全相同，manifest SHA256 为 `dcf566507557ac1056cf4a8d2620c697920f49a0d391dfeaf6e692c5678424a0`。

共享包包含 512×384/s2048 和 1024×1024/s64 两个源实例，1376×768/s64 由第二个源运行时实例化。它不为三个尺寸保存三套权重。复制后的新包已校验，未重复声称又执行了一次出图。

在源码根目录重新构建后，可运行：

```sh
build/ernie-image --model models/turbo-shared \
  --prompt 'A red apple on a wooden table, soft daylight, realistic photo.' \
  --width 1376 --height 768 --precision fp32 --text-down-vector \
  --steps 8 --seed 42 --output outputs/shared-1376.png
```

这是使用原生 RNG 的普通生成命令；精确复现本次对照须按 `worker-result.json` 使用同一保存的 `--latent`。本机本次图片位于 `outputs/runtime-shape1376-v1/native/validation/native.png`。模型、二进制、图片和大张量没有加入 Git。
