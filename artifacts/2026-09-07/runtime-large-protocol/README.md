## 执行及停止规则

沿用之前的实验资源保护：模型进程组 16GiB、禁用该组 swap、CPU 4/6 两核额度；主机可用 RAM 不低于 3GiB、整卡 GPU 采样不超过 6144MiB、每个 native/official 阶段不超过 1800 秒。它们是助手选定的本次实验设置，不是 ERNIE/ncnn 官方要求或产品硬件门槛。比较阶段单独限制为 4GiB 和 2 核。GPU 观测包含桌面等其他进程，cgroup 包含文件缓存，不能冒充完整 allocator 峰值或原生 RSS。

原生通过独立网络命名空间执行，原项目目录隐藏、模型只读；官方参考也禁用网络。启动前真实验证四组隔离环境、原生帮助和全部 1744 项绑定，共 17 项预检通过。13 个小型编排测试通过，包含完整性失败、矛盾/缺失结果拒绝、数值未通过后继续以及执行失败后停止。

严格使用旧门槛：conditioning NRMSE 0.0002、atol 0.0002、global rtol 0.0002；其余 FP32 NRMSE 0.003、atol 0.0002、global rtol 0.01；PNG 平均通道差 ≤0.1、最大差 ≤2。初始输入须完全相同，所有张量须形状正确且有限，两边 PNG 须等于对应 decoded 张量的量化结果。门槛由助手选定，未完成广泛感知标定；数值失败不直接证明内存不足或明显画质损坏。

每个独立尺寸有效完成比较但未过数值门槛时，保留 `numerical_failure`，继续下一个已冻结尺寸，整个批次最终退出 1。执行失败、资源终止、缺失/无效比较立即停止批次，保留输出，不自动重试。新规则不覆盖旧方图批次遇到 768 数值未通过即停止的历史记录。

本目录仅记录准备与协议，不代表四个完整样例已经完成。后续状态以 `/var/tmp/ernie-runtime-large-v1/progress.json`、实际进程及每阶段的 `process.json` 为准。较大的噪声、二进制和源文件快照保留本地，见 `retained-local-files.json`。不将本轮视作自动显存耗尽恢复、正式性能/同业比较、广泛质量或完整功能验收；不关闭超过参考项目的整体目标。
