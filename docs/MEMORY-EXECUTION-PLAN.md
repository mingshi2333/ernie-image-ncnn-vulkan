基线为 00b6e64，ncnn 为 3b7bdba7。旧缓存结果与数值门槛继续保留。

1. 修复 ncnn RAM 权重的外部内存声明和复制用途；固定原始文件摘要，编译构建目录副本；Vulkan 校验诊断进入 CTest 失败条件。
2. 每次最多异步准备下一块 Net。独立预算、主机余量检查、请求内生命周期、后台错误传回主线程；与现有权重缓存配合。默认关闭。
3. DiT 激活和工作区使用同一可控分配器：GPU 优先，压力或分配失败时转为 GPU 可访问的主机内存；实际 host 分配受预算和主机余量限制。临时 buffer 只在 GPU 完成后回收。
4. 保存每个完成 Euler 步的 FP32 latent。可恢复的分配失败销毁失败尝试的资源，从最近检查点恢复；关闭预取与权重缓存、优先 RAM 权重和激活，并把 FP32 注意力查询块从 128 逐级减到 16。保持分辨率、精度、步数、K/V 和调度不变。重试有上限，设备丢失、无效模型和数值错误不重试。
5. 记录预取次数/执行区间重叠、主机 buffer 峰值、回退与重试次数；测量事实不推导为加速保证。

验证依次覆盖源文件守卫、真实小型 Vulkan 计算、异步生命周期/预算/异常、故障注入与检查点恢复、完整同输入图像回归、安装 SDK 和已授权三平台 CI。重资源测试串行执行。工作区、RAM buffer 计账和进程/整卡峰值分别报告。
