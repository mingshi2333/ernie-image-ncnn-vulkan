**S 的基准选择：** 校准阶段枚举事先声明的小型配置网格，选出对方通过共同质量标准的最快配置，再冻结；我们必须用对应的每阶段公开精度配置通过同一质量要求，内部 mixed-precision 差异完整列出。允许各自合理的设备调度，但不能靠降低精度、少跑步数或关闭 PE 满足 S。若无法对齐精度或证明模型权重等价，只能补充标为“不同配置/来源未完全证实的产品比较”，不能关闭 S；真正一致的组件比较才标为“同精度”。对方不能运行或不能通过共同质量标准时，该项速度比记为 unavailable，不能当作无限加速或删除。

**Q 的含义：** 相同权重下，目标是可靠还原模型并维持提示遵循，不承诺改变模型本身的能力。盲评至少两名独立人工评审，随机左右、隐藏实现名，按提示遵循、文字、数量/关系、明显瑕疵分别打分。主指标为我们的胜出份额（平局计 0.5），按提示词聚类 bootstrap 的 95% 区间下界 ≥ 0.45；不满足时只能报告未证明不劣。更高画质的声明另需区间下界 > 0.5。

**D 的边界：** macOS 小模型通过只支持对应范围的声明，不等于真实 8B 全模型验收；AMD/Intel 硬件全模型支持也必须有各自记录。硬件或公开发布尚不可用时，标为交付待验证，不能把软件 Vulkan 当硬件通过。

- 独立场景固定覆盖中英日文、文本排版、计数、空间关系、人物、写实/插画、低对比度与长描述。正式结果只在候选冻结后揭示，不能按正式失败案例手工调精度再用同一结果声称独立验证。

- 形状 canary 为 `64×64, 512×384, 384×512, 512×512, 768×768, 1024×1024, 1376×768, 768×1376, 2048×1024, 1024×2048`；超限应在加载大权重前拒绝。

- 主性能时钟从启动进程至 PNG 写完，含模型验证、文本、PE（如启用）、解码和 I/O。不得仅比较 DiT 后将其称为端到端。trace/profiling 与正式计时分轮。
- 使用同一主机电源/性能配置、CPU 线程数网格、驱动与磁盘；记录温度、频率、后台负载。预先规定干扰事件处理，整对标记失效并补测，不只重跑较慢一侧。

## 6. 停止错误方向的规则

1. 独立算子更精确但完整轨迹无改善，候选不晋升默认；保存负结果。
2. 预取只隐藏等待却增加峰值/交换，或只有组件加速而端到端未改善，记录后撤回默认。
3. 低精度未过固定质量门槛，继续标为实验；不能靠对某条提示词特判或放宽门槛关闭问题。
4. 对方完整构建失败先修正已知根目录入口，在单独适配补丁中记录兼容性修复；不能把文档入口错误当作性能胜利。
5. S/M 目标不满足则继续优化或报告未超过。任何目标修改都建立新版本和理由，保留原目标失败状态，不能悄悄降标。
6. P4 的外部硬件、人工评价或发布权限缺失时，继续完成可执行的本地工作；最终分别标明技术完成与外部验收状态。
